# AutoTD

北航阳光体育锻炼（TD 线）自动打卡工具。

**平台：Android 手机端**（目前仅支持 Android）

- 系统要求：Android 7.0 及以上
- 安装包大小：约 5 MB
- 无需 Root，无需电脑

## 下载

到 [Releases](../../releases/latest) 页面下载最新版 APK。

## 使用

1. 安装 APK（首次安装需允许「安装未知来源应用」）
2. 打开后输入学号，选择校区
3. 系统设置里开启「自启动」和「后台运行」
4. 点「开始打卡」，锁屏等待即可
